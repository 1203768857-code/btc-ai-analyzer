# 每周 GitHub 好物 · 2026-11-03

这份清单来自 GitHub 本周热门榜（trending），时间是 2026-11-03 上午（香港时间）。这周上榜的项目，大多数都要配合 Claude Code 才能用。

## 1. anthropics/skills

- **链接**：<https://github.com/anthropics/skills>
- **一句话用途**：Anthropic 官方 AI 技能包合集，让 AI 会处理 Word、PPT、PDF 等文档。
- **适合场景**：已经在用 Claude Code，想让它处理文档的人。
- **怎么上手**：在 Claude Code 里输入 `/plugin marketplace add anthropics/skills`，再输入 `/plugin install document-skills@anthropic-agent-skills`。

## 2. obra/superpowers

- **链接**：<https://github.com/obra/superpowers>
- **一句话用途**：给 AI 编程助手定一套先想、再做、后检查的做事规矩。
- **适合场景**：让 AI 写小程序、小网站，又怕越写越乱的时候。
- **怎么上手**：在 Claude Code 里输入 `/plugin install superpowers@claude-plugins-official`。

## 3. heygen-com/hyperframes

- **链接**：<https://github.com/heygen-com/hyperframes>
- **一句话用途**：用写网页的方式做视频。
- **适合场景**：做产品介绍短片、字幕动画、幻灯片式视频。
- **怎么上手**：装好 Node.js 后运行 `npx skills add heygen-com/hyperframes`，选 Core Skills。

## 4. TauricResearch/TradingAgents

- **链接**：<https://github.com/TauricResearch/TradingAgents>
- **一句话用途**：多个 AI 扮演分析师、研究员、风控，围绕一只股票讨论。
- **适合场景**：只适合学习参考，不是投资建议。
- **怎么上手**：运行 `git clone https://github.com/TauricResearch/TradingAgents.git && cd TradingAgents && pip install .`，配置 AI 服务 API 密钥后运行 `tradingagents`。

## 5. ghostty-org/ghostty

- **链接**：<https://github.com/ghostty-org/ghostty>
- **一句话用途**：更快更好看的命令行窗口。
- **适合场景**：开始学敲命令的时候用。
- **怎么上手**：去 <https://ghostty.org/download> 下载安装。
